# EcoVenue · Gestió Eficient i Sostenible d'Espais

Plataforma web per a la gestió concurrent de reserves d'espais per a esdeveniments amb càlcul d'impacte ambiental (ODS 11 i 13).

## Estructura del projecte
- `/frontend`: Aplicació client (HTML, CSS, JS / Fetch API).
- `/backend`: API REST (Node.js/Express, PHP/Laravel o Django).
- `/docs`: Documentació tècnica, esquemes E/R i wireframes.

## Stack tecnològic previst
- **Frontend:** HTML5, CSS3, JavaScript (ES6+).
- **Backend:** Node.js / Express (o PHP/Laravel).
- **Base de dades:** PostgreSQL / MySQL.
